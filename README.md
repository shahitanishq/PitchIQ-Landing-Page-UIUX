# 🏏 PitchIQ – Cricket Performance Platform UI/UX Design

## 📌 Project Overview

PitchIQ is a modern, responsive landing page UI/UX design for a fictional cricket performance technology platform. The platform aims to help aspiring cricketers improve their game through performance tracking, cricket analytics, and personalized training insights.

This project is developed as part of a college UI/UX design assignment using Figma.

## 🎯 Project Objectives

* Design an attractive and professional cricket-tech landing page.
* Create a simple and intuitive user experience.
* Make the design suitable for desktop and mobile screens.
* Use Figma Auto Layout and reusable components.
* Maintain consistent colors, typography, and spacing.
* Demonstrate responsive UI/UX design principles.

## 👥 Target Audience

* Aspiring cricketers.
* Amateur and recreational cricket players.
* Young athletes looking to improve their performance.
* Cricket enthusiasts interested in performance analytics.

## 🎨 Design System

### Color Palette

* Deep Navy: `#0B1120`
* Lime Green: `#B8F34A`
* Slate Navy: `#172235`
* White: `#FFFFFF`
* Muted Grey: `#94A3B8`

**Typography:** Inter

**Design Style:** Modern, minimal, premium sports-tech aesthetic with dark backgrounds, vibrant lime accents, clean typography, and a strong visual hierarchy.

## ✨ Website Sections

1. **Navigation Bar** – PitchIQ logo, navigation links, and Get Started button.
2. **Hero Section** – Main headline, description, call-to-action buttons, and cricket visual.
3. **Statistics Section** – Highlights player statistics and platform metrics.
4. **Features Section** – AI Shot Analysis, Performance Tracking, and Personalised Training.
5. **How It Works** – Explains the three steps: Upload, Analyse, and Improve.
6. **Call-to-Action Section** – Encourages users to begin their cricket improvement journey.
7. **Footer** – Logo, navigation links, and social media links.

## 🛠️ Tools and Technologies

* **Figma:** UI/UX design, Auto Layout, reusable components, responsive frames, and design system.
* **GitHub:** Project documentation, screenshots, and sharing.

## 📱 Responsive Design

The design includes layouts for the following screen sizes:

* Desktop: 1440px
* Mobile: 390px

The mobile layout adapts the desktop design by stacking content vertically, resizing typography, adjusting spacing, and making feature cards suitable for smaller screens.
